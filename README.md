# Анонимные сообщения — Telegram-бот

Бот для анонимных сообщений в любых группах. Владелец чата добавляет бота к себе, участники пишут в чат анонимно через личку бота.

## Как это работает
- Бот добавлен в группу → он регистрирует чат и присылает кнопку «✉️ Написать анонимно».
- Под каждой анонимкой тоже есть эта кнопка — искать её не нужно.
- Участник открывает бота: если он в одном чате с ботом — чат выбирается сразу, если в нескольких — список кнопок.
- Ответ (Reply) на анонимку в группе приходит автору в личку; автор отвечает через Reply — ветка продолжается.
- Писать можно только в чат, участником которого ты являешься.

## Модерация
- `/anonban` — Reply на анонимку: автор теряет возможность писать в этот чат, сообщение удаляется. ID автора нигде не показывается.
- `/anonunban` — снять бан.
- `/anonon`, `/anonoff`, `/settopic`, `/media on|off`, `/cooldown N` — настройки чата (только админы).
- Владелец бота: `/stats`, `/gban ID`, `/gunban ID`, `/broadcast текст`.

## Запуск
```bash
pip install -r requirements.txt
cp .env.example .env   # вписать BOT_TOKEN и OWNER_ID
python main.py
```
Чтобы бот сам находил чаты участника, сделайте его админом в группе (или в BotFather: `/setprivacy` → Disable).
